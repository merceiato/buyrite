3. Technical Notes
------------------------------------------------------------

Frontend:
- Single Page Application (SPA) using:
  - HTML, SCSS and JavaScript (ES6)
  - lit-html for templating
  - Shoelace web components (via CDN)
  - Parcel bundler
- All views are rendered into <div id="root"> via a small custom router.

Backend:
- Node.js + Express REST API
- MongoDB Atlas via Mongoose
- JWT-based authentication for protected routes
- Multer + Sharp used for avatar upload, resizing and storage
- express-fileupload used for product image uploads
- Public images served from:
  - /images/[filename] on the backend (mapped to /public/images)

Key Routes:
- POST  /auth/signin         – user login and token
- GET   /auth/validate       – validate JWT and return user data
- POST  /user                – create new user (sign up)
- GET   /user/:id            – fetch user (authenticated)
- PUT   /user/:id            – update user fields and optional avatar image
- GET   /product             – public list of active products (consumer)
- GET   /product/vendor      – vendor’s own listings (auth + vendor only)
- POST  /product             – create product (vendor)
- PUT   /product/:id         – update product (vendor)
- DELETE /product/:id        – delete product (vendor)

5. Quick Setup / Deployment Summary (for future reference)
------------------------------------------------------------

Backend (EC2 / Node):
- Clone or copy the backend folder to the server.
- Run:
  - npm install
  - npm install mongodb   (in case it’s not already installed)
- Create a .env file with:
  - PORT=3000
  - MONGO_URI=<MongoDB Atlas connection string>
  - ACCESS_TOKEN_SECRET=<random secret string>
- Start the server with:
  - npm start
  or:
  - npx pm2 start server.js --name buyright-api

Frontend (Netlify or similar):
- From the frontend folder:
  - npm install
  - npm run build
- Deploy the dist/ folder to a static host (e.g. Netlify).
- Make sure the API base URL in App.js matches the backend URL.

These notes are just to remind me how to get everything running again later if I need to redeploy or move servers.
